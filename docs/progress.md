## Milestone 2

The companion uses the installed Superwhisper file-transcription CLI. Right Alt captures the selected PulseAudio microphone and the companion sends the resulting text to the same focused WoW process. Wine required explicit Control key-down and key-up events around V. Passing a modifier mask alone typed a literal v.

Verified on goose using the Forever client, a virtual Right Alt press and release, and a virtual audio source. The integrated build delivered one self-whisper. Switching to an empty workspace restored the stock Omarchy shortcuts and recording indicator. The Superwhisper Linux working tree remained clean. Physical keyboard and microphone input still need a hands-on check.

## Milestone 3

The integrated build opened the approved Listening box on a virtual Right Alt press. A recorded utterance selected WoW's native whisper header and delivered the message to the same character. The self-whisper used a temporary speech replacement for the character name, removed after the check. The QA harness held Enter until the recipient was visually verified. F12 is the stock backpack key on Forever, so the companion uses Ctrl+Shift+F12. All nine channel prefixes passed Lua tests; only whisper was sent live.

## Milestone 4

Verified the addon's core terms in the installed Superwhisper vocabulary. After a self-whisper, /sww sync reloaded the UI, wrote one name to SavedVariables, and the live watcher added it while the game remained focused. Switching workspaces restored the original settings document exactly. Tests cover ownership, restart recovery and parsing. Guild, Battle.net and raid roster collection were not exercised with populated rosters.

## Milestone 5

The installer copied the addon and companion into the local Forever installation. Compared installed files with the checkout and used the installed copies for the in-game checks. A temporary prefix also passed the installer smoke test.

## Windows stage 1

Source inspection confirmed that Windows saves recordings under Unix-second folders on release, writes modeName and the final results to meta.json, and writes the transcript to the clipboard even with Auto paste disabled. Capture the clipboard before recording and verify the completion belongs to the WoW mode. The companion never edits Superwhisper's configuration.

On a hosted Windows desktop, the x64 companion observed push-to-talk, opened the binding on a foreground fixture named Wow.exe, pasted the completed recording, sent one Enter and restored the clipboard. Switching focus canceled delivery. The installer and uninstaller passed with a disposable game directory and the current user's sign-in registry entry. The [Windows run](https://github.com/superultrainc/superwhisper-wow/actions/runs/44386743802) includes the package and fixture screenshot. Real Superwhisper, in-game delivery and a fresh Windows sign-in remain untested.
