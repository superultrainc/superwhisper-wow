3 · Channel headers (spoken first word)

Uses WoW's own slash commands, so the header and colour are the game's. Shown here in the Listening state after the channel word is recognised. Note: the channel is only known after release, so while you're holding the key the header shows the last-used channel.

System-message yellow, like the game's own command output. Only /sww sync and /sww (help).
